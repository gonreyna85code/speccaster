# SpecCaster — Marketing

This directory contains SpecCaster's marketing strategy, positioning, and growth infrastructure.

## Files

| File | Purpose |
|------|---------|
| `product-marketing.md` | Canonical product marketing context (ICP, problem, positioning, differentiators, objections) |
| `strategy.md` | Growth strategy, bottleneck analysis, phase plan |
| `positioning.md` | One-liner, elevator pitch, comparison positioning |
| `icp.md` | Ideal customer profiles with behavioral signals |
| `competitors.jsonl` | Competitor intelligence (JSONL format) |
| `voice-of-customer.jsonl` | Customer pain points extracted from real discussions |
| `keyword-map.jsonl` | Target keywords with intent, competition, priority |
| `channel-map.jsonl` | Distribution channels with status and expected impact |
| `experiments.jsonl` | Marketing experiments with hypothesis, metrics, decisions |
| `content-map.json` | Content inventory, gaps, and SEO opportunities |
| `objections.md` | Customer objection map with responses and proofs |

## Principles

1. Qualified attention over volume
2. Activation over impressions
3. Revenue over engagement
4. Evidence over assumptions
5. Kill what doesn't work, scale what does
